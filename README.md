# homebrew-mdlook

Homebrew tap for [mdlook](https://github.com/lemehmet/mdlook), a terminal
markdown reader that reflows paragraphs to your terminal width and turns
search into a navigable index of matches.

```sh
brew install lemehmet/mdlook/mdlook
```

The formula installs the prebuilt binaries from mdlook's
[releases](https://github.com/lemehmet/mdlook/releases) — macOS (Apple Silicon
and Intel) and Linux (x86-64 and arm64). It is updated automatically by
mdlook's release workflow; issues and contributions belong in the
[main repository](https://github.com/lemehmet/mdlook), where the formula
template lives at `packaging/homebrew/mdlook.rb`.
